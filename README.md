# 📊 Sales Tracker Using Google Sheets

## 📌 Project Overview
This project is a Sales Tracker developed using Google Sheets to organize sales data, calculate sales totals, and present key business metrics in a simple dashboard.

## 🎯 Objectives
- Track daily sales.
- Calculate weekly sales totals.
- Calculate monthly sales totals.
- Monitor total sales, total orders, and quantity sold.
- Visualize sales performance using a chart.

## 🛠️ Tools Used
- Google Sheets
- Spreadsheet formulas
- Data Validation
- Charts and Data Visualization
- GitHub

## 📂 Project Structure
- Raw Data: Contains the original sales dataset.
- Summary: Displays daily, weekly, and monthly sales totals.
- Sales Overview: Presents key sales metrics and a column chart.

## 📈 Key Features
- Daily sales calculation using SUMIFS.
- Weekly sales calculation using SUMIFS.
- Monthly sales calculation using SUMIFS and EDATE.
- Data validation for the quantity column.
- Automatic calculation of total sales, total orders, and total quantity sold.
- Column chart for comparing daily, weekly, and monthly sales.

## 📊 Key Metrics
- Total Sales
- Total Orders
- Total Quantity Sold
- Daily Sales
- Weekly Sales
- Monthly Sales

## 💡 Conclusion
This project demonstrates how Google Sheets can be used to organize sales data, apply formulas, validate entries, summarize business performance, and visualize important sales metrics. It provides a simple way to monitor sales and support data-driven decisions.
